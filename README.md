## Cara kerja

1. Jalankan `python3 main.py` untuk menghasilkan satu baris teks epitaph ke `/output/entry.txt`
2. File `main.py` menulis teks satu baris dengan batas maksimal 150 karakter
3. Output divalidasi panjang karakter sebelum commit

Setiap perubahan pada punchline dilakukan dengan edit kecil pada kalimat `main.py` lalu dijalankan ulang untuk verifikasi. Versi ini menggunakan teks "Error 404: Afterlife not found (yet)" sebagai punchline.
